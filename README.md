# 360GO Design Studio — v1.0.0

محرر تصميم مستقل وتجريبي باللغة العربية، مصمم ليُدمج لاحقًا في لوحة إدارة 360GO بعد مراجعة ملفات المشروع الأصلي.

## التشغيل

يتطلب Node.js 18 أو أحدث:

```bash
npm install
npm run dev
```

ثم افتح الرابط المحلي الذي يظهر في الطرفية.

## الوظائف
- تعديل لون الهوية
- إظهار وإخفاء شريط الأخبار العاجلة والإعلانات
- ترتيب الأقسام بالسحب والإفلات على الكمبيوتر أو بالأسهم على الهاتف
- تغيير عناوين الأقسام وأحجامها وإخفاؤها
- معاينة الكمبيوتر والهاتف
- حفظ مسودة محلية في المتصفح وتصدير/استيراد JSON

## حدود النسخة
- لا توجد اتصالات مع قاعدة بيانات أو GitHub أو WordPress أو موقع 360GO المنشور.
- لا توجد مصادقة أو صلاحيات أو نشر فعلي.
- حفظ المسودة في localStorage على الجهاز والمتصفح الحاليين فقط؛ يمكن نقل الإعدادات باستخدام JSON.
- السحب باللمس غير منفذ بعد؛ الأسهم تعمل على الهاتف.
- الأقسام بيانات نموذجية وليست تصنيفات المشروع الأصلية.
- لا ترفع مجلد node_modules أو ملفات .env أو أسرار إلى GitHub.

## الدمج لاحقًا
بعد استرجاع ملفات 360go-frontend الأصلية، نراجع هيكلها وواجهات API والمصادقة والتصنيفات ثم ننقل المحرر ونربط حفظ الإعدادات بالخادم مع التحقق من الصلاحيات وإمكانية معاينة المسودة قبل النشر.
